# Структура репозитория

- [`ML/`](ML/) – приложение Taipy в `app/`, скрипты и артефакты обучения в `model/`, отчёты и скриншоты проекта в `docs/`.
- [`DV/`](DV/) – работы по курсу. Исходники в `src/` и `typst/`, изображения в `img/`, готовые отчёты в `pdf/`.
- `materials/` – локальные датасеты и материалы курса. Каталог игнорируется Git.
